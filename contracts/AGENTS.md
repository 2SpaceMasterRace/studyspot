# Contract Instructions

This directory owns formats shared across frontend, API, search, and data work.

- Keep the study-spot summary aligned with the root `AGENTS.md`.
- Store representative, non-secret examples in `sample-data/`.
- Validate every sample document against the shared schema once the schema lands.
- Treat removing or renaming a field as a breaking change.
- Request review from every affected area before merging a contract change.
